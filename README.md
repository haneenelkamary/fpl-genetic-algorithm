# Fantasy Premier League Team Optimization Using a Genetic Algorithm

A Python project that uses a Genetic Algorithm (GA) to select a Fantasy Premier League (FPL) squad under the standard squad constraints and a £100.0m budget. It uses expected points from the official FPL public API data collected by `main.py`.

## Features

- Downloads current player and fixture data from the FPL public API.
- Saves player data to `data/players.csv` and fixture data to `data/fixtures.csv`.
- Uses a Genetic Algorithm to search for a 15-player squad.
- Enforces squad composition:
  - 2 Goalkeepers
  - 5 Defenders
  - 5 Midfielders
  - 3 Forwards
- Enforces the £100.0m budget and a maximum of 3 players from any one club.
- Selects a starting XI, captain, and vice-captain based on the available expected-points and availability data.
- Saves the selected squad to `data/best_squad.csv`.

> Note: The current Genetic Algorithm reads `data/players.csv`. Although `main.py` also downloads fixtures into `data/fixtures.csv`, the current optimization code does not use fixture data directly when scoring players.

## Requirements

- Python 3.10 or newer recommended
- `pandas`
- `requests`

## Project Structure

```text
fpl-genetic-algorithm/
├── main.py
├── genetic_algorithm.py
└── data/
    ├── players.csv       # generated by main.py
    ├── fixtures.csv      # generated by main.py
    └── best_squad.csv    # generated by genetic_algorithm.py
```

The `data/` directory and CSV files do not need to be uploaded to GitHub. The scripts create the `data/` directory and download fresh data when you run `main.py`.

## Setup and Usage

### 1. Clone or download this repository

Clone the repository from GitHub, or download it as a ZIP file and extract it.

### 2. Open a terminal in the project folder

Make sure the terminal's current directory is the folder containing `main.py` and `genetic_algorithm.py`.

### 3. (Recommended) Create and activate a virtual environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, you can either use Command Prompt and run:

```bat
.venv\Scripts\activate.bat
```

or run the Python commands below using the environment's Python executable.

### 4. Install dependencies

```bash
python -m pip install pandas requests
```

### 5. Download the latest FPL data

```bash
python main.py
```

This downloads player and fixture data from the public FPL API and saves the CSV files in `data/`.

An internet connection is required. The API data can change throughout the season, and the project depends on the API being available.

### 6. Run the Genetic Algorithm

```bash
python genetic_algorithm.py
```

The algorithm reads `data/players.csv`, searches for a valid squad, prints the starting XI, bench, captain, vice-captain, squad cost, and expected points, then saves the result to `data/best_squad.csv`.

## How the Genetic Algorithm Works

The implementation uses:
- **Initial population:** randomly generated valid squads.
- **Fitness function:** expected points of the best legal starting XI, including the captain's additional expected points.
- **Selection:** tournament selection.
- **Crossover:** combines players from two parent squads while preserving the required position counts.
- **Mutation:** attempts to replace a player with another player in the same position while preserving squad validity.
- **Elitism:** carries top-performing squads into the next generation.

The search is stochastic in general, but the current script sets a random seed for reproducibility with the same input data and environment.

## Data Source

Player and fixture data are retrieved from the public Fantasy Premier League API:

- API base endpoint: `https://fantasy.premierleague.com/api/`
- Player/team/gameweek data: `bootstrap-static/`
- Fixtures: `fixtures/`

The project is an educational optimization project and is not affiliated with or endorsed by the Premier League.

## Troubleshooting

- **`Players data not found`:** Run `python main.py` first from the project directory.
- **Missing Python packages:** Run `python -m pip install pandas requests`.
- **No upcoming gameweek:** The API may not currently identify a next gameweek; the player download can still complete.
- **No valid squad found:** Check that `main.py` completed successfully and created a current `data/players.csv` file.
